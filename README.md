## Descripción
Este proyecto consistirá en una aplicación web para gestionar reservas de forma sencilla.
Los usuarios podrán registrarse, iniciar sesión, consultar disponibilidad y realizar o cancelar reservas.
El proyecto parte de los conocimientos adquiridos el año anterior, donde desarrollamos una aplicación web
utilizando Python, FastAPI, Supabase, PostgreSQL y JavaScript.

## Tecnologías
- **Frontend:** React, para crear una interfaz moderna, dinámica y organizada por componentes.
- **Backend:** Python con Django, para desarrollar la lógica de negocio y una API para gestionar las reservas.
- **Base de datos:** PostgreSQL mediante Supabase, aprovechando también sus herramientas de autenticación.
- **Diseño:** CSS y librerías compatibles con React para crear una interfaz responsive.
- **Documentación:** Markdown dentro del repositorio de GitHub.
- **Control de versiones:** Git y GitHub utilizando `main` como rama principal.

El reto de este año será pasar de una aplicación más básica a un proyecto full-stack más completo,
utilizando frameworks específicos tanto para frontend como para backend y aprovechando herramientas
que permitan cubrir autenticación, base de datos, API, interfaz y despliegue.
